# 问题3：双班组多工序协同作业的最优调度

## 1. 问题重述

同时使用班组1和班组2的全部现有设备，完成 A、B、C、D、E 五个车间的整修任务。每个车间内部的工序顺序固定；设备可以重复服务不同工序，但一台设备同一时刻只能执行一道工序；设备首次从所属班组驻地运往车间以及跨车间转移均消耗运输时间。目标是在满足工程量、工序先后关系、设备容量和运输约束的前提下，使全部任务的最终完工时间最短。

## 2. 模型假设

1. 同一类型、同一班组内的设备性能完全相同，两个班组的同型设备作业效率也相同。
2. 一道工序对某类设备投入多台时，工程量在这些设备间等量分配，各设备同时开始且不可中断。
3. 若一道工序需要两类设备，两类设备同时开始，各自完成该工序的全部工程量；工序结束时刻取两类设备完成时刻的较大值。
4. 设备在同一车间连续执行不同工序时运输时间为0；跨车间运输时间按“距离÷2 m/s”向上取整到秒。
5. 每台设备首次运输的起点为其所属班组驻地，班组1和班组2的初始距离分别按附件取值。
6. 车间间距离视为对称距离；设备完成最后一道任务后无须返回班组驻地。
7. 不考虑设备故障、维护、人员换班及其他未给出的准备时间。

## 3. 符号说明

- `I`：展开后的工序集合。C3-C5重复3遍，分别记为 C3-1 至 C5-3。
- `W={A,B,C,D,E}`：车间集合。
- `R`：设备类型集合。
- `M_r`：类型 `r` 的全部具体设备集合，包含两个班组的设备。
- `q_i`：工序 `i` 的工程量。
- `v_ir`：设备类型 `r` 在工序 `i` 上的作业效率。
- `w(i)`：工序 `i` 所属车间。
- `g(m)`：设备 `m` 所属班组。
- `tau_uv`：车间 `u` 至 `v` 的运输时间。
- `tau_gw^0`：设备从班组 `g` 驻地首次运至车间 `w` 的时间。
- `S_i、C_i`：工序 `i` 的开始和完成时刻。
- `C_max`：五个车间全部任务的最终完成时刻。

## 4. 工序持续时间

若工序 `i` 对设备类型 `r` 投入 `n` 台同型设备，则每台设备承担 `q_i/n` 的工程量。该设备类型的持续时间为

`p_ir(n)=ceil(3600*q_i/(v_ir*n))`。

引入二元变量 `y_irn`，当且仅当投入 `n` 台设备时取1：

`sum_n y_irn = 1`，

`p_ir = sum_n p_ir(n)*y_irn`。

对需要两类设备的工序，两类设备在 `S_i` 同时开始，分别在 `S_i+p_ir` 完成，故

`C_i = max_{r in R_i}(S_i+p_ir)`。

这一表达严格落实了题目中“各类设备均须完成相应工程量，全部完成后工序才算完成”的规定。

## 5. 设备分配模型

定义二元变量 `x_irm`：若工序 `i` 的设备需求类型 `r` 选用具体设备 `m`，则取1。设备数量一致性约束为

`sum_{m in M_r} x_irm = sum_n n*y_irn`。

因此，模型不是预先指定每道工序使用多少台设备，而是在1台至该类型全部可用设备之间自动选择，并同时确定具体设备编号和所属班组。

## 6. 车间内部工序先后约束

若工序 `j` 是工序 `i` 在同一车间的直接后继工序，则

`S_j >= C_i`。

五条工序链为：

- A1→A2→A3；
- B1→B2→B3→B4；
- C1→C2→C3-1→C4-1→C5-1→C3-2→C4-2→C5-2→C3-3→C4-3→C5-3；
- D1→D2→D3→D4→D5→D6；
- E1→E2→E3。

## 7. 设备不重叠与运输约束

对每台具体设备建立带虚拟仓库节点0的有向访问回路。令 `a_mij=1` 表示设备 `m` 完成工序需求节点 `i` 后紧接着服务节点 `j`；令 `f_mi=1` 表示 `i` 是设备 `m` 的第一项任务。

若设备由工序 `i` 转向工序 `j`，则

`S_j >= S_i+p_ir+tau_{w(i),w(j)}-H(1-a_mij)`。

若工序 `i` 是设备 `m` 的第一项任务，则

`S_i >= tau_{g(m),w(i)}^0-H(1-f_mi)`。

其中 `H` 为足够大的时间上界。回路的流入、流出度约束与设备分配变量联立，使每台已启用设备形成唯一的任务访问序列；未被选择的任务节点通过自环跳过。于是，一台设备不可能同时参加两道工序，且相邻任务间自动留足运输时间。

## 8. 目标函数与求解算法

主目标为

`min C_max`，

`C_max = max(C_A3,C_B4,C_C5-3,C_D6,C_E3)`。

模型采用 OR-Tools CP-SAT 求解。该问题同时含有离散设备台数选择、具体设备分配、带序列相关运输时间的设备路径和工序链约束，属于典型的混合柔性作业车间调度问题。CP-SAT能够利用约束传播、冲突学习、割平面和分支定界直接给出严格下界；与遗传算法、模拟退火等启发式算法相比，它可以在求解状态为 `OPTIMAL` 且目标值等于严格下界时证明全局最优。

为减少等价解，只在同一班组内部对同型设备编号施加“低编号优先启用”的对称性消除约束。班组间设备的初始位置不同，不能做跨班组对称化。主目标达到全局最优后固定 `C_max`，再以 `sum_i C_i` 最小为次级目标进行限时紧凑化；次级求解只改善方案展示，不影响主目标的全局最优性。

## 9. 最优结果

CP-SAT返回：

- 主目标状态：`OPTIMAL`；
- 最优总工期：`73575 s = 20:26:15`；
- 严格下界：`73575 s`；
- 相对最优间隙：`0.000000%`。

因此，20:26:15不是当前搜索到的较好值，而是在本模型和题设口径下已经证明的全局最短时间。与仅用班组1的 144880 s 相比，缩短 71305 s，即约49.22%。

## 10. 方案校验

程序在脱离CP-SAT内部约束后，对导出的结果再次执行独立校验：

1. 每个车间的相邻工序均满足“后序开始时刻不早于前序完成时刻”；
2. 每道工序的每类设备分配工程量之和等于原始工程量；
3. 持续时间等于 `ceil(工程量×3600/(效率×设备台数))`；
4. 每台具体设备的相邻任务满足“不重叠+运输时间”；
5. 五个车间末道工序完成时刻的最大值等于73575 s。

全部校验通过。完整的219条设备—工序分配记录见“表3_问题3结果.csv”，含运输与等待信息的扩展记录见“问题3_最优设备调度方案.csv”。

## 11. 模拟退火交叉验证与最优解存在性

另行建立不调用OR-Tools的贪心—模拟退火程序。该算法把五个车间的工序链交织顺序作为染色体，使用串行调度生成机制枚举每道工序的设备投入台数，并选择能够最早到达相应车间的具体设备。退火邻域为交换两个不同车间的优先位置，在保持各车间内部工序顺序不变的条件下搜索。

贪心初解为86565 s。使用随机种子20260820、20260821、20260822和20260823分别搜索，四次均得到73575 s，与CP-SAT结果完全一致。不同试验得到的非关键工序和具体设备编号可以不同，说明该问题存在多组等价最优排程，但最优目标值相同。

模拟退火属于启发式算法，只能说明“再次找到一个73575 s的可行解”，不能独立证明不存在更短方案。全局最优性的严格依据仍是精确算法给出的

`可行解上界73575 s = 分支定界严格下界73575 s`。

此外，本题工序数量有限、每类设备数量有限、设备投入台数和设备访问顺序的组合均有限；将全部任务依次执行即可构造至少一个可行解。因此可行集合非空且离散有限，最小总工期必然能够取到。综上，问题3不仅存在最优解，而且73575 s已经被严格证明为全局最优总工期。
